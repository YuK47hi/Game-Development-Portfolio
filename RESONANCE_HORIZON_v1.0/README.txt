　AI Visual Novel  ×  3D Stereoscopic Rhythm Session

■ ゲーム概要
本作は、AI少女「アリア」と深層コアの守護者「ノア」との対話を描く「ノベルパート」と、
多次元の電脳空間で立体的なビートを刻む「3Dリズムゲームパート」がシームレスに融合した、
新感覚のハイブリッド・ノベルリズムゲームです。

プレイヤーの選択肢によって物語の結末が変化する「マルチエンディング」を搭載しています。


■ 起動方法
1. 同梱の「RESONANCE_HORIZON.exe」をダブルクリックしてください。
※ 本パッケージは .NET ランタイム同梱の自己完結型（Self-Contained）形式のため、
　 外部ソフトの事前インストールなしに即座にプレイ可能です。


■ 基本操作方法
【タイトル・ノベルパート】
・マウスクリック / Spaceキー : 会話を進める / 選択肢の決定
・ESCキー                    : ゲーム終了

【リズムゲームパート】
・奥から手前に向かって流れてくるノーツが、手前の判定枠（ライン）に重なった瞬間に
　対応するキーを押してください。
　[ D ] : 左レーン（ピンク）
　[ F ] : 中央左レーン（ブルー）
　[ J ] : 中央右レーン（グリーン）
　[ K ] : 右レーン（ゴールド）
・目標スコア（Stage 1: 3,000点 / Final Stage: 5,000点）に達するとクリア演出が発動し、
　次のストーリーへと進みます。


■ 動作環境（推奨）

・画面解像度: 1280 x 720 以上
・オーディオ: DirectSound / OpenAL 対応サウンド環境
