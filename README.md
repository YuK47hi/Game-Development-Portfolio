# 制作物・ソースコード用

## リポジトリ概要

### 1\. タイム・リンク・シューター (STG 3D)

概要: PCの現実時間（朝・昼・夕・夜）とリアルタイムにリンクする環境光・スカイボックス制御と、180秒生存をかけた緊迫の3D空間全方位STGです。

\*\*開発環境:\*\* Unity / C# (URP) | 制作期間: 約4ヶ月（個人制作）

操作方法:

\-**【移動・回避】WASD（前後左右移動）、Q/E（旋回・バレルロール回避）**

\-**【攻撃・視点】Space（弾丸発射）、C（三人称視点/カメラ切り替え）**

\-**【システム】制限時間180秒生存、R（即時リトライ）、F（タイトル復帰）**

技術的工夫・主な機能:

* URP環境での動的環境光・ライティング制御により、システム時刻に応じた太陽光角度・スカイボックス回転・環境光カラーを補間計算し、滑らかな時間変化を表現。
* Z軸境界値判定（$Z > 50$）および生存時間（3秒）による Destroy 自動削除アルゴリズムを徹底構築し、大量の弾丸・彗星によるメモリ圧迫を防いで60FPSを維持。
* 重い物理演算を避け、CompareTag（タグ判定）と Trigger Collider を組み合わせた軽量かつ確実な衝突処理・スコア加算ロジックを実装。
* 激しい自機操作でも視認性を損なわない3D追従カメラ制御を構築し、180秒タイマーの色変化やカメラ振動（減衰アルゴリズム）で緊張感を演出。

### 2\. AI Visual Novel × 3D Stereoscopic Rhythm Session 「RESONANCE HORIZON」

概要: ノベルパートと128BPM同期の4レーン3D立体リズムセッション作品です。

\*\*使用技術:\*\* C# (.NET 8.0) / MonoGame

技術的工夫・主な機能:

* 「PCM波形数値計算によるフルプロシージャル・オーディオ（ProceduralAudio.cs）」を実装し、指数減衰や高調波合成によるRIFF WAVEの動的生成を実現。
* 消失点とZ軸奥行きの非線形補間を用いた「擬似3Dパースペクティブ立体描画エンジン」を完全自作実装。

### 3\. 仮想OS・簡易ファイルシステムシミュレータ

概要: メモリ上に仮想領域を確保し、低レイヤーの仕組みを再現したファイルシステムのシミュレーションです。

\*\*使用技術:\*\* C言語 / 低レイヤー

技術的工夫・主な機能、特徴:

* **FAT (File Allocation Table) 構造の模倣、ディレクトリエントリ割り当て、ブロック単位のRead/Write処理をC言語で実装。**
* **低レイヤーにおける堅牢なポインタ操作やメモリ構造体管理の基礎技術を修得。**

**-ファイルシステムと永続化: バイナリファイルシリアライゼーション（fwrite / fread 等）を活用したデータの書き込み・読み込み構造**

\-**メモリ管理**: 堅牢なポインタ操作とデータ構造によるメモリの動的管理

\-**シェルコマンド実装**: ls（ファイル一覧）, touch（ファイル作成）, write（書き込み）, rm（削除）などの基本コマンド自作
