# 制作物・ソースコード用

## リポジトリ概要

###  1.RESONANCE_HORIZON
概要: 独自のシナリオ管理とリッチな演出機能を備えた、C++ / DXライブラリ製の2Dビジュアルノベルゲームです。

-**使用言語・環境**: C++, DXライブラリ

主な機能・特徴:

-**シナリオ・テキスト制御**: スムーズな文字送り、ログ表示、オートモード、テキストスキップ等の高度なメッセージコントロール実装

-**ビジュアル・演出管理**: キャラクターの立ち絵差分切り替え、背景描画、画面フェード等の動的な演出処理

-**データ永続化（セーブ・ロード）**: プレイヤーの進行状況やフラグ管理、システム設定のファイル入出力構造

-**サウンド統括管理**: BGMやSEのシームレスな再生切り替えと、ボリューム調整等のオーディオ制御

###  2. OS
概要: C言語の低レイヤーな仕組みを活かして実装した、仮想ファイルシステムおよびコマンドラインベースの簡易OSシミュレーションです。

-**使用言語・環境: C言語**

特徴:

-**ファイルシステムと永続化**: バイナリファイルシリアライゼーション（fwrite / fread 等）を活用したデータの書き込み・読み込み構造

-**メモリ管理**: 堅牢なポインタ操作とデータ構造によるメモリの動的管理

-**シェルコマンド実装**: ls（ファイル一覧）, touch（ファイル作成）, write（書き込み）, rm（削除）などの基本コマンド自作
